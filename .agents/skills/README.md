# Skills Directory

This directory contains custom skills for this workspace. Each skill should have its own directory containing a `SKILL.md` file.

## Example Structure

```
.agents/
  skills/
    my_custom_skill/
      SKILL.md
      scripts/
      examples/
```

## SKILL.md Example

```yaml
---
name: my_custom_skill
description: A brief description of when to use this skill
---

Here you put the markdown instructions for the skill.
```
